#### **二、 数据加密与安全机制**
为了让您充分了数据保护机制，我们依据《个人信息保护法》第十七条，向您告知以下核心安全设计 ：

1. **主密钥（您的核心机密）**：您需自行设置并保管一串至少12位、包含3类及以上字符（大写字母、小写字母、数字、特殊符号）的“主密钥”。**此密钥是您数据的唯一访问凭证，仅存储于您的本地设备，我们及任何第三方服务器均无法获取。请务必妥善保管，因主密钥泄露导致的任何数据风险将由您自行承担。**
2. **本地加密**：**所有账号信息在上传前，均在您的本地设备完成加密**。加密采用国际标准的 **AES-SIV 算法**，确保数据的机密性与完整性。
3. **密钥派生**：用于访问云端和加密数据的密钥，均通过抗暴力破解的 **Argon2id 算法**（参数：memory_cost=256MB、time_cost=3、parallelism=2）从您的主密钥派生而来。这意味着：
    - 上传至云端的仅为“派生标识符”和“加密后的密文”。
    - 任何第三方（包括云服务提供商）即便获取了云端数据，也无法反向破解出您的主密钥或原始账号信息。
4. **传输加密**：加密后的数据在传输过程中，采用 **HTTPS 协议**进行二次加密传输，防止数据在网络传输环节被窃听或篡改。
